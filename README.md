# SENTINEL Defense Systems — Website

A static, multi-page marketing website for **SENTINEL Defense Systems** (a fictional
brand), built with plain HTML, CSS, and vanilla JavaScript. No build step and no
external dependencies — it runs directly in any browser.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Home — hero, about, capabilities overview, CTA |
| `systems.html` | Platform / systems catalogue |
| `capabilities.html` | Capabilities brief |
| `contact.html` | Contact form + FAQ |

## Assets

- `style.css` — all styling (dark, defense-tech theme)
- `script.js` — mobile nav, scroll-reveal, animated counters, FAQ accordion,
  front-end-only contact form, live UTC clock

## Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

This site is served via **GitHub Pages** from the `main` branch root.
